# Recipes

Three jobs, worked end to end, with the actual commands. Deliberately unrelated to each other
so the routing logic is visible rather than memorised.

| Recipe | Teaches |
|---|---|
| [01 — product hero shot](01-product-hero.md) | Single image, bounded motion, camera move in post |
| [02 — a two-state transformation](02-transformation.md) | Keyframe pairs — the highest-value pattern here |
| [03 — one character across five shots](03-character-sequence.md) | Identity across a sequence, and edit-derivation |

Read [`../AGENTS.md`](../AGENTS.md) first. These assume you know the routing rules; they show
what following them looks like in practice.

A note on the commands: `aar` is `python3 cli/aar.py`. Alias it if you're going to use it more
than once.

```bash
alias aar='python3 '"$PWD"'/cli/aar.py'
```
